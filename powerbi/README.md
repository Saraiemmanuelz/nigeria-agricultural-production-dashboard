# Power BI files

- `Nigeria_Agri_Dashboard.pdf`: PDF export of all four dashboard pages.
- Put your `.pbix` file here (for example `Nigeria_Agri_Dashboard.pbix`) before you push. The `.pbix` is the editable report, and anyone with Power BI Desktop can open it.
- If your `.pbix` is over 100 MB, GitHub will reject it. Use Git LFS or attach it to a GitHub Release instead.
